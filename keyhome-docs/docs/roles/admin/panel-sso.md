# Admin Panel SSO

## Feature Description

The **Panel SSO (Single Sign-On)** mechanism enables seamless navigation from the Next.js frontend to the **Laravel Filament admin panel** without requiring a separate login. When an admin user logs in via the Next.js API, the backend returns a `panel_sso_url` that auto-authenticates them in the Filament panel.

---

## How It Works

```
Admin logs in via POST /auth/login
 
 Response includes: { access_token, user, panel_sso_url }
 
 Frontend redirects to panel_sso_url (e.g. https://api.keyhome.cm/admin/sso?token=...)
 
 Laravel PanelSsoController validates the token
 Creates Filament admin session → redirects to /admin
```

The `panel_sso_url` is a **time-limited signed URL** generated by the `PanelSsoController` on the backend. It contains a one-time token that creates a Filament session for the user.

## Frontend Implementation

### SSO Redirect in AuthProvider

```typescript
// src/providers/AuthProvider.tsx
const finalizeAuth = (token: string, user: User, panelSsoUrl?: string) => {
 persistInMemoryToken(token);
 setUser(user);
 setRoleCookie(user.role);

 if (user.role === 'admin' && panelSsoUrl) {
 // Redirect admin directly to the Filament panel via SSO
 window.location.href = panelSsoUrl;
 return;
 }
 if (user.role === 'agent') {
 window.location.href = '/owner/dashboard';
 } else {
 router.push('/home');
 }
};
```

---

## Security Considerations

- The SSO token is **single-use** and **short-lived** (expires in minutes)
- It is transmitted only via HTTPS redirect, never stored on the frontend
- The Filament panel has its own session-based authentication with **TOTP MFA** enabled
- Even with SSO, the Filament panel enforces its own authorization policies
