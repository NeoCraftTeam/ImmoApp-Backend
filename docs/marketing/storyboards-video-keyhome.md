# Contenu vidéo KeyHome — livrables montage

**Recommandation format vidéo principale :** **16:9 (1920×1080)** — YouTube, Facebook in-feed, LinkedIn, pré-roll. Déclinaison **1:1 (1080×1080)** par recadrage centre pour Instagram/Facebook feed si un seul master.  
**Palette :** rose client `#F6475F` · fonds midnight `#141419` + halo crimson (cf. charte affiches). **Produit :** MacBook / navigateur **keyhome.app** uniquement — pas de mockup smartphone.

**Écarts mineurs vs docs existants :** les visuels marketing standardisent le CTA **« Accéder à la plateforme »** + pastille `keyhome.app` ; ici le brief demande **« Rechercher maintenant »** en CTA vidéo — les deux sont compatibles (bouton recherche sur la home). Ne pas afficher **Mobile Money** à l’écran ; la VO peut mentionner brièvement les **crédits** (consultation gratuite, déblocage contact) sans promettre « tout gratuit ».

## Fiche technique commune (3 vidéos)

| Élément | Recommandation |
|--------|----------------|
| **Résolution** | 1080×1920 (vertical) · 1920×1080 (principale) |
| **FPS** | 25 ou 30 |
| **Sous-titres** | FR intégrés (gros, fond semi-transparent) |
| **Typo** | Sans-serif bold (style Inter / Geist) · blanc sur fond sombre |
| **Musique** | Afro-pop instrumentale moderne, sans paroles · -14 LUFS approx. |
| **Voix** | Homme ou femme 25–40 ans · ton conseil, pas ton « pub télé » |
| **Assets UI** | Captures réelles **keyhome.app** (preprod/prod) · flouter données perso |
| **Interdits visuels** | Mockup smartphone · Mobile Money · promesses « zéro arnaque » · « garanti légalement » |
